== Introduction

This document presents the collections and their properties used in lab 1. They are extracted from the inferred schema of the `mflix-sample` using the Couchbase 'INFER' command. To simplify comprehension we represent them in the TypeScript format. 

- Attributes that can be missing are represented by '`?`'
- Arrays are represented by appending '`[]`' to the element's type

For example: 

[source,typescript]
----
let example_collection: [
  string, // key of the collection
  {
    optionalAttr?: number  // an attribute that can be missing (but not null)
    nullableAttr: null | boolean  // an attribute that can be null or a boolean (but not missing)
    arrayOfStrings: string[];  // an array with String elements e.g. [], ["first", "second", ...], ...
    arrayOfObjects: {
      objAttr: number;
    }[]  // an array with object of a specific structure e.g. [], [{objAttr: 1}, {objAttr: 2.2}, ...], ...
  }
]
----
